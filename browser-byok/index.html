How this page handles your key

  • Held in a single JavaScript variable. Not in localStorage, sessionStorage, or cookies.
  • Sent only to api.anthropic.com over HTTPS. Verify in DevTools, Network tab.
  • No third-party scripts on this page. No analytics, no fonts, no external libraries.
  • Closing the tab, refreshing the page, or clicking Clear key wipes the variable.
  • Keys are never logged to the console, never written to any file, never sent anywhere except Anthropic.
